# Sobre o projeto
Este projeto foi desenvolvido com o objetivo de analisar o desempenho de vendas de um e-commerce utilizando Power BI.
O dashboard apresenta indicadores estratégicos, gráficos interativos e análises visuais que ajudam a identificar tendências de vendas, produtos mais vendidos, regiões com maior desempenho e evolução do lucro ao longo do tempo.
A proposta do projeto é transformar dados em informações claras e organizadas para auxiliar na tomada de decisões.

# Base de Dados
A base de dados utilizada contém informações relacionadas às vendas de um e-commerce, incluindo:

• Nome dos produtos
• Categorias
• Regiões
• Datas de pedidos
• Quantidade vendida
• Valor de vendas
• Lucro obtido

Os dados foram utilizados para desenvolver análises estratégicas focadas em desempenho comercial e comportamento de vendas.

# Tratamento de Dados
Durante o desenvolvimento do dashboard, foram realizados tratamentos e padronizações nos dados para melhorar a visualização e interpretação das informações.

Principais tratamentos realizados:

• Tradução de categorias e produtos para português
• Padronização de nomes
• Formatação de valores monetários em Real (R$)
• Ajuste de títulos e campos para melhor visualização
• Organização de colunas para análise no Power BI
• Criação de segmentações interativas

# Medidas Criadas
• Lucro Total
• Vendas Totais
• Quantidade Vendida
• Total de Produtos
• Média de Lucro

# Análises
• Análise de vendas
• Comparação entre categorias
• Desempenho regional
• Evolução das vendas
• Produtos mais vendidos
• Análise de lucro

# Insights
• Categorias com maior venda
• Regiões mais lucrativas
• Produtos com maior desempenho
• Crescimento das vendas ao longo do tempo

# Objetivo do Projeto
Desenvolver um dashboard interativo no Power BI para transformar dados de vendas em informações visuais e estratégicas através da análise de dados e criação de KPIs.
